本项目改编自上游 [Xanerix/guoapp](https://github.com/Xanerix/guoapp)（原名「小果影视」）的源码，上游则重建自原作者 [fish2018](https://github.com/fish2018) 的开源项目。安装包内置红果站源，其余站源以模块形式在 **我的 › 模块** 安装。

> [!WARNING]
> 项目处于开发阶段，不对用户数据做担保，数据可能在版本更新时丢失。

## 功能

- **浏览**：发现 / 追剧 / 我的。手机底栏，电视顶部 Tab。分类浏览、搜索、详情选集，滑到底自动加载。
- **播放**：竖屏短剧沉浸式，上下翻页切集，滑动调亮度音量；横屏视频竖拿时视频在上、选集在下，转横屏自动全屏。下一集提前预热，切换无感接上；红果在线播放有弹幕。
- **追剧与记录**：追剧有更新自动置顶，观看记录按时间分段，可搜索、筛选、多选删除。
- **下载**：详情页选集下载，每集自动转成普通 mp4 保存为 `下载目录/剧名/第 N 集.mp4`，可直接拷出使用。
- **多用户与备份**：多用户独立数据，管理员可设权限；支持导出 / 恢复备份。

## 安装

| 架构 | 说明 |
| --- | --- |
| arm64-v8a | 大多数手机选这个 |
| armeabi-v7a | 32 位旧设备 |
| 整合包 32+64 | 不确定架构时选这个 |

同一签名可覆盖升级；提示 `INSTALL_FAILED_NO_MATCHING_ABIS` 表示架构不匹配，请换对应安装包。

## 使用说明

- **首次打开**：默认「管理员」用户不设密码；红果站源已内置，打开 **发现** 就能看。
- **站源模块**：**我的 › 模块** 里从在线仓库安装，或用 zip / 链接手动安装；只能装模块，不能直接填网址。
- **播放设置**：倍速、解码方式在 **设置 › 播放**；弹幕样式与屏蔽词在 **设置 › 弹幕**。
- **常见问题**：站源加载失败先下拉刷新或换代理（**设置 › 代理**）；反馈问题时附上 **设置 › 诊断 › 播放调试日记** 的日志。
